Install

One line, a container, or a chart.

One binary in ~/.local/bin, checked against the release's sha256. No root.

curl -fsSL https://jgermade.github.io/luu/setup.sh | sh
wget -qO- https://jgermade.github.io/luu/setup.sh | sh
  • Linux x86_64
  • Linux arm64
  • macOS Apple Silicon
  • macOS Intel

luu serve in a container, its state and its work tree in volumes. The image is ghcr.io/jgermade/luu, for amd64 and arm64.

docker run -d --name luu --restart unless-stopped \
  -v luu-state:/state -v luu-work:/work \
  -p 7878:7878 ghcr.io/jgermade/luu

The token, written on the first start:

docker exec luu cat /state/token

Then open http://localhost:7878/?token=…. deploy/compose.yaml puts Caddy in front for TLS on a name of your own.

One pod, its volumes kept on uninstall, behind an Ingress of any class. The chart is oci://ghcr.io/jgermade/charts/luu.

helm install luu oci://ghcr.io/jgermade/charts/luu \
  --set ingress.enabled=true \
  --set ingress.host=luu.example.com \
  --set ingress.tls.enabled=true

The token:

kubectl exec deploy/luu -- cat /state/token

Then open https://luu.example.com/?token=…. Without an Ingress, kubectl port-forward svc/luu 7878. The policy it runs under is policy: in its values.

Installer options

With no command the script asks what to do. Pass one after sh -s --, for example sh -s -- install --dir ~/bin. It never edits a shell profile: when the directory is not on your PATH, it prints the line to add.

install · reinstall · uninstall
Asked for when none is given, offering reinstall and uninstall only when luu is already there. install does nothing when that version is already there; reinstall always downloads again.
--dir DIR
Where the binary goes. Default ~/.local/bin, or LUU_INSTALL_DIR.
--version TAG
A release such as v0.1.1. Default the latest, or LUU_VERSION.
--purge
With uninstall: also delete sessions, keys, config.toml, engines and models. Asks first.
-y, --yes
Do not ask before deleting — needed for --purge when there is no terminal.
LUU_DOWNLOAD_URL
A directory with luu-<target>.tar.gz and SHA256SUMS, used instead of GitHub: a mirror, or file:// for your own build.
