# A second local model, warned about

Row 73 of [`ROADMAP/2026-11-08`](../ROADMAP/2026-11-08/README.md): step 5 of
[`sessions-side-by-side`](2026-10-30.sessions-side-by-side.completed.md), §4:
*starting a session on a second local model is allowed, and the dialog says
what is already loaded and how much memory it holds, before the click.* The
record stayed `WIP` on this alone.

## The problem

Several sessions can be live at once, and each can send to its own engine.
Two 14B models on a 24 GB machine are found by the machine swapping, or by an
engine that never comes up, after the click.

## What there is to say, and what it costs to know

- **What is loaded**: `Supervisor::model_of` per engine, a process this server
  started and the model it was started on.
- **What a session would load**: `engines::for_run` on the provider and model
  the dialog has chosen, the same resolution `serve` runs when the session
  starts.
- **How much memory**: two candidates.

| | The process's resident memory | The weights' file |
| --- | --- | --- |
| Where | `/proc/<pid>` on Linux, `ps` on macOS | `models::catalog`, already listed |
| Before the click, for the model not loaded yet | not knowable | known |
| On a GPU, or Metal's unified memory | misses most of it, or counts mmapped pages twice | the same number |

The file is the only number that exists for both sides of the comparison, and
the one a person can check. It is not the whole: the context's KV cache comes
on top, and the dialog says *weights*, not *memory*.

## The proposal

`GET /api/engines/beside?provider=&model=`:

```json
{ "loads":  { "engine": "second", "model": "luu:second.gguf", "label": "second (luu)", "size": 5000000000, "sessions": 0 },
  "loaded": [ { "engine": "first", "model": "luu:first.gguf", "label": "first (luu)", "size": 4000000000, "sessions": 1 } ] }
```

`sessions` counts the live sessions whose profile names that engine. The
dialog asks it whenever the provider or model changes, and says one of three
things under the provider and model:

| Case | Said |
| --- | --- |
| no engine, or the same engine on the same model | nothing |
| another engine holds something | *Already loaded: first (luu) (4.0 GB) on first. Starting here loads second (luu) (5.0 GB) beside it — about 9.0 GB of weights together.* |
| the same engine holds another model for a live session | *Engine first holds … for 1 live session. Starting here reloads it on …, and that session reloads its own on its next turn* |

The third is not in §4. One engine is one process on one model, and
`Supervisor::ensure` restarts it on whichever model the call in hand asked for,
so two sessions on two models of one engine take turns reloading it. Nothing
prevented that before and nothing does now; it is said.

It warns and does not refuse, as §4 decided: the machine's memory is not
something luu measures, and a refusal on a guess would be wrong on every
machine with more of it than the guess.

## What it costs

One route and its serde shapes in `serve.rs`, one catalog walk per ask on a
blocking thread, and about forty lines in the dialog.

## What was rejected

- **Resident memory.** Above.
- **Asking on Start.** A dialog after the click is the click asking twice; the
  warning is in the same place as the choice it is about.
- **Total memory on the machine, and a verdict.** It would need a model of what
  each engine kind keeps where, per platform; not this row.

## Found on the way

The dialog's helper was first called `named`, and the component already had a
`const named` for sessions' titles. jq79 took the later one without a word and
the warning read *Already loaded: false on first*. Named `modelSaid` now. The
console was silent about the collision; only the test's text caught it.

## Still open

- **The same-engine case is not exercised by a test.** It needs a live session
  on a local engine, and a fake `llama-server` that sleeps does not answer the
  health check a session's turn waits on.
- **Continue here** moves the live session, so the engine it leaves may be
  released afterwards; the warning is worded for *Start session* and is shown
  for both.
- **An engine luu did not start** (an Ollama app already running) is not in
  `loaded`: `model_of` knows only this server's children.
