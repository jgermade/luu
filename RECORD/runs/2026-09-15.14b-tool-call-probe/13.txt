`Mock::cycle` is a method for the `Mock` struct that determines how the replies cycle when they run out. By default, it is off, meaning that once the replies run out, the last one repeats indefinitely. When `cycling` is set to `true`, the list of replies wraps back to the first element instead of sticking on the last one. This allows for a `call, answer` pair to become a tool that is invoked on every turn of a script of any length, rather than just once at the start of the session.
