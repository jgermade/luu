`Mock::cycle` is a method for the `Mock` struct that determines how the replies are handled when they run out. When `cycling` is set to `true`, the list of replies wraps back to the first element instead of sticking on the last one. This means that a `call, answer` pair can become a tool invoked on every turn of a script of any length, rather than once at the start of the session. When `cycling` is `false`, the last reply repeats indefinitely.
