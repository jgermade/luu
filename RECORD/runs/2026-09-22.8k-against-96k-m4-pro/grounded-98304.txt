> where does selected code get fused, and why not above the system block?

- **Where:** Into the *current* user message, as late in it as possible — below the stable prefix, never above it.
- **Why not in the system block:** The system block is the stable prefix the prompt cache reuses, and it must stay byte-identical across turns. Fusing it into the current user message keeps the cached prefix untouched while still letting the model see the code.

> why is there no deny list in this policy?

Because **Landlock is allow-only** — it grants access, it can't subtract from it. So the policy is pure allowlist (trees + programs), and the way to deny something is simply **not to grant it**.
