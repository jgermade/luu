## The shape of the day, in one line

**Closing item 6 is what opened item 19, and item 19 is a defect in what item 6
turned on.** The flip was decided on the 2026-09-14 run — twenty grounded
questions, no verdict moved — and that corpus edits nothing, so it could not
contain the one case where a span needs re-reading. Six hours later the same
neighbourhood produced a prompt that carries one file twice with different
bodies, by default, because of the rule the morning turned on.

Neither half is wrong. The flip is right about what it measured and the defect is
about what it did not. Both sentences are in the tree now, in the records that
own them, which is the only outcome where the next reader can tell them apart.

## Found while doing it, none of it by a test written for the purpose

**Nine tests had used *the default* as a name for *the arm without rule A*.**
Seven were one-flag-apart comparisons for rules B and C whose corpora are one
span carried by three turns — exactly what rule A collapses — so after the flip
they measured two rules and reported one. They now name `Repeat::Always` on the
baseline, which is this project's own *one flag apart* discipline applied to a
default that moved underneath it.

**One of them had become a test that could not fail.**
`the_rule_never_evicts_more_than_the_default_would` built `plain` from
`Budget::new` and `once` from that same budget `.repeating(Repeat::Once)`. After
the flip both arms were the same budget, `once.evicted <= plain.evicted` held
trivially across a sweep of seventy window sizes, and the only thing standing
between the commit and a green tautology was a `kept_more > 0` guard written on
2026-09-07 for an unrelated reason — *a range of windows where the rule changes
nothing is a range that proves nothing*. Worth its own line: the guard was
written about rigour eleven days before the thing it caught existed.

**`--no-repeat-once` was already itemised as owed.** `resend_rules`' doc comment
said the off-switch *"is not here because no default has flipped"* and the
precedence test asserted its absence as a limitation. Finding the bill written
down by the people who knew it would come due is the argument for that kind of
comment, and it is cheaper to record than to re-derive.

**The page had never had to say what *unset* means.** `settings-resend.html`
offers *unset*, *always* and *once*, and the distinction it drew — *a machine
stating no position* against *a machine choosing off* — was safe to leave
implicit only while those two landed on the same behaviour. They no longer do:
pressing **unset** on Repeat now gets the rule **on**. A control whose label was
true by coincidence, which is the same class as §tenth's `put_resend` finding the
day before. Flipping a default is a reliable way to find them.

**A roadmap section header had been wrong since the day it was written.**
Section B of `ROADMAP/2026-09-17` opened *not one of them has been measured
against a model on the axis that would justify turning it on* while item 6, two
rows down in the same file, carried the measurement that says otherwise. The flip
made it doubly wrong and that is how it was noticed. Corrected in place with the
correction visible, because a section header is exactly the sentence nobody
re-reads.

## What it cost

- **A format bump, 11 → 12**, for the `diverged` trace line, with the page's
  constant moved in lockstep because `ui_versions.rs` is the pair that makes it.
- **Two behaviour changes for every existing user**, which is what flipping a
  default is: `chat`, `stdio` and `serve` all render spans once unless told
  otherwise. Every recorded arm stays readable and every future one says which
  side it was on, which is what format 11 landed for the day before.
- **`repeat` takes an `Option<bool>` where the other two rules take `bool`**, and
  the asymmetry is real rather than tidy: only the rule whose default moved owes
  an off-switch, and saying so in one place beats making all three symmetric for
  the look of it.
- **19 files, +1 308 / −128.** Roughly half of that is two records.

## Verified rather than asserted

Both halves were checked outside the test suite, because this project's rule is
that a number carries its backend or it is not a number.

- **The flip, on the wire**: `luu chat` with no flags records `"repeat": "once"`,
  with `--no-repeat-once` records `"always"`, format 11 → 12 both times. Part 1
  of the previous record existed so that part 6 could be checked this way.
- **The defect, end to end**: three turns of `luu chat`, one `write_file` through
  the real sandbox, and turn 3's prompt carries `// greeting.py` twice — `return
  "Hello, "` and `return "Hi, "`. No relevance selection, no window pressure, no
  eviction. Two `## fragment:` lines and a tool call.
- 479 Rust tests, 16 live-server browser tests, clippy at `-D warnings` and fmt.
