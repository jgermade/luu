## What is owed, in order

1. **Row 69: merge PR #70 and cut v0.1.6.** The landing and `setup.sh` show
   `luu config`, the online mode, links and the chart's new values, and the
   release they install does not have them yet.
2. **Rows 70 and 71, before a second real person is let in.** Isolation is
   tested at the API, not under the image's Landlock. The mail has met only a
   fake server. Row 64's two gaps (a cargo home per user, Landlock's signal
   scoping) belong to the same afternoon as row 70.
3. **Row 58: roles in the page.** On a server with users every Settings write
   is refused today, an owner's included. People are managed with `luu user`
   on the machine, and what a server offers linked luus (`offer = false`) is
   set in its file. This is the row that makes a public luu manageable from
   its page.
4. **Row 59: passkeys.** The plan's last step, after a check that WebAuthn can
   be had without OpenSSL.
5. **Rows 62–63: a cluster**, and with it the LoadBalancer from row 72.
6. **Row 72's code: links' leftovers.** Of these, removing `[host.*]` is a
   decision before it is code.

**One question to the person, unanswered.** The phone's three slides (chat,

## Picking it up

- **Branch.** Once PR #70 is merged, from `main`. Before that, from
  `claude/eager-euler-fn1dim`.
- **Building in a cloud container.** `cargo build -j 4` with
  `CARGO_INCREMENTAL=0`: at full parallelism the worker was killed once
  (exit 137), and `target/` grows past 20 GB. CI's clippy is Rust 1.99:
  `CARGO_TARGET_DIR=target/r199 cargo +1.99 clippy --workspace --all-targets
  -- -D warnings`, and `rm -rf target/r199` afterwards for the disk.
- **A flaky test.** `terminal::tests::a_command_on_a_pty_is_on_a_terminal_and_hears_what_is_typed`
  failed once in a full run on 2026-11-04 and passed five times alone and in
  the next full run. Not looked into. `--no-fail-fast` keeps one failure from
  hiding the other binaries' results.
- **The smoke suites** (`tests/smoke`) pin their own `@playwright/test`; CI
  runs them. Locally, the container's own Playwright reproduces what they
  check, as was done for the Remote access spec.
- **Two servers by hand**, the way the pages were checked:

  ```sh
  # a luu that accepts links, and one that dials it, on this machine
  printf '[server]\nbind = "127.0.0.1:7971"\nssh = "127.0.0.1:7973"\n' > $B/config.toml
  printf '[server]\nbind = "127.0.0.1:7972"\n' > $A/config.toml
  LUU_HOME=$B luu link allow laptop "$(LUU_HOME=$A luu link key)"
  LUU_HOME=$B luu serve --no-store &
  LUU_HOME=$A luu link add http://127.0.0.1:7971 --name laptop --as workstation
  LUU_HOME=$A luu serve --no-store &
  ```

  For the online shape, `[server] exposure = "public"` and an `origin` on
  `$B`, a user (`luu user add`), and `luu user key add` instead of `link
  allow`. A long `LUU_HOME` puts the links' socket in `<temp>/luu-<uid>/`,
  because a socket's path has 108 bytes at most.
- **A dangling link from before this branch:**
  `RECORD/runs/2026-09-16.plain-js-rows/rows.html-arm.js` names
  `2026-09-16.the-viewer-in-plain-js.WIP.md`, renamed `completed` since. It
  is a run's evidence, and was left as it is.
