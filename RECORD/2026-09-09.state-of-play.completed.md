## What the reordering was, and why

The order written on the morning of 2026-09-08 held nine rows, and every one of
them was a measurement, an argument or a box. None of them was the surfaces a
person works in. The owner's priority was the other way round — *before
performance runs and tuning models: the UI configuring providers, a development
panel over the activity, and the three things worth trying soonest — the chat,
the manual supervision of commands, and execution in the container* — so the
revision was rewritten in place with a section A ahead of everything it already
held. See [`the-surfaces-first`](2026-09-08.the-surfaces-first.completed.md).

The reordering turned out to be cheaper than it read: **three of the four things
asked for were already built**, and the work was to *drive* them rather than to
write them.

## Three bugs, and none of them was found by a test

This is the finding of the night, and it is the argument the reordering rested
on rather than the preference that prompted it.

1. **A plan that granted a file could not read it.** Since 2026-09-05, on every
   platform, at the gate — which is the ordinary case, because a model asked what
   it needs names files. Found in the first ten minutes of driving the gate over
   the socket with the page's own messages.
2. **The page could not open a session at all.** `record::FORMAT` went to 8 with
   rule B and `store.js` still said 7, so the host refused every `hello` and
   closed the socket; the only visible symptom was the word `closed` in a corner,
   because the reconnect loop wiped the refusal every few seconds. Found by the
   first run of the browser test being written to prevent exactly this.
3. **A posture's `name` vanished when it was `null`.** Found by the container job
   in CI, minutes after the feature landed — and the Rust test that asserted the
   same field passed, because `serde_json` answers a missing key with `null`.

Each now has a test that would have caught it: a file-root grant in
`tools::fs`, `crates/luu/tests/ui_versions.rs` pairing the two version constants
across two languages, and an assertion that the key is present rather than
merely null.

## What is measured now that was not

- **Level 3 holds on Linux.** Landlock **ABI v7** + seccomp + rlimits, inside
  stock Docker on a GitHub runner (`Linux 6.17.0-1022-azure`), with no
  `--privileged` and the default seccomp profile. Three data points in the
  inventory now — v8 in Docker Desktop's VM, v10 native on machine 4, v7 here —
  and the lowest of them still holds the child.
- **The per-job filter and the per-session posture are two things**, shown in one
  line: a job approved with no network, inside a posture that allows one, reports
  `seccomp (no sockets, no ptrace)` where every other contained run reports
  `seccomp (ptrace)`.
- **What a fold saves**, at all: `34 → 33` on the smoke session's tiny corpus. The
  number is worthless and the *unit* is not — both sides come from one counter at
  one moment, which is what makes the next one worth reading.

## What it cost

- **Two format bumps in one night**, 8 → 9 → 10, each additive to an existing
  message and each moving the page's constant in the same commit. That is only
  cheap because item 2 landed first; on 2026-09-08 the same drift had the UI dead
  on `main` for a day.
- **Section B did not move.** *Whether a 7B misses the repetition* was correctly
  called the cheapest unbought answer in the project, and it is still unbought —
  the flag exists, the corpus exists, the model is on machines 1 and 4, and rule A
  stays off for a reason nobody has measured. The tool-call probe and the grammar
  slipped with it, in their own order, unchanged.

## Still open

- **Concurrency.** `serve` runs one live session at a time; sessions are
  switched, not run side by side. A per-session `Agency` is the first half of
  what concurrency would need, and the rest is not designed.
- **Nobody has measured what a container start costs**, so *the worker starts
  with the session* is chosen on the shape of the thing rather than on a number.
  The `container` job already runs the same call on both sides and is the obvious
  place the number comes from.
- **A session resumed under a different posture** is visible in the header and
  refused by nothing. The store keeps jobs and their approved plans; it does not
  keep what they were approved under.
- **No model has ever run inside a container.** Every contained run, here and on
  the Mac, is the mock — and the trigger `luu.container.toml` names for narrowing
  its network is the first `run_command` inside one with a model in the loop.
- **Nothing counts how often a plan grants a file rather than a directory**, which
  is the number that would say how ordinary bug 1 was.
- **The trace channel still has no consumer.** `/ws/trace` carries the agent's own
  lines, including the `pruned` ones rule B added, and nothing in the page reads
  them.
