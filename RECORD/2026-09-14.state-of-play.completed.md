## The shape of the day, in one line

**Two rows that had been waiting on a machine got one, and closing them built
the tool that closed the two rows after them.** Item 1 sat at the top of two
roadmap revisions for exactly the reason this file's predecessor named — *a
rule that is built, measured on tokens and never measured on answers is the
most expensive kind of unfinished work this project produces, because it
looks finished.* Machine 1 was on hand; the run took an afternoon's shape and
answered it. Item 3b had been blocked on a corpus that could not exist under
the mock's old semantics — measuring it meant building `--mock-cycle` first,
and once built it also unblocked item 4's harness, which reused it rather
than inventing a second way to get a call on every turn.

## Found while doing it, none of it by a test written for the purpose

- **`--prune-behind` alone is a complete no-op on a tool-heavy conversation.**
  Not a partial saving, not a smaller number — 15 prune moves, all 15 freed
  zero tokens, on a corpus of 20 turns each dominated by one maximal tool
  result. This was always true of the shipped code (rule B has never walked
  `ToolStep`); nothing until today's corpus could show a number for it,
  because nothing before `--mock-cycle` could build a conversation where a
  tool is called on every turn.
- **The mock backend always reports `prompt_tokens: 0`.** True since the mock
  existed and not something either measurement run needed to know until this
  session tried to sum `usage.prompt_tokens` across a mock run and got zero
  every time — the aggregate numbers in
  [`what-rule-c-is-worth`](2026-09-14.what-rule-c-is-worth.completed.md) are
  read from the `budget` trace instead, which is what the mock actually
  reports honestly.
- **A dangling link, eight files wide, predates this session.** `../loude-design.md`
  — `luu-design.md` misspelled — appears in eight completed records back to
  2026-08-26. It was not fixed here: `RECORD/` is append-only, and a link
  inside a finished record is content, not a rename. Naming it is what this
  section is for; fixing it is a decision for whoever is willing to touch a
  completed record's body, which this project's own rule asks nobody to do
  lightly.
