# Relevance selection: In-degree and non-greedy fill

**Status:** a proposal and the code it plans. It is item 4 of
[`ROADMAP/2026-09-04/README.md`](../ROADMAP/2026-09-04/README.md), following
[`2026-09-02.ranking-the-map.completed.md`](2026-09-02.ranking-the-map.completed.md) and
[`2026-09-03.the-map-order-probe.completed.md`](2026-09-03.the-map-order-probe.completed.md).

## Problem

PageRank ranking failed on the 38-question neutral corpus
([`the-map-order-probe`](2026-09-03.the-map-order-probe.completed.md)):
1. **Precision collapse (12.5% vs 100% path order baseline)**: PageRank pushed
   weight to deep sinks and dense files (`session.rs`), starving entry-points and
   top-level coordinator modules.
2. **Oversized file trap & greedy fill stoppage**: In `RepoMap::build`, the fill
   rule halts at the very first file that exceeds the remaining token budget. When
   rank order places a huge file (`session.rs`, ~1200 tokens) near the top, once
   budget is partially consumed, all remaining smaller files are unconditionally
   dropped. At 4096 tokens, path order fit 15 files while rank order fit only 8.

## Proposal

1. **In-Degree Ranking (`Order::InDegree`)**:
   Instead of PageRank's iterative random-walk damping (which penalizes modules with
   high fan-out but low cyclic feedback), calculate direct weighted in-degree:
   $$\text{score}(u) = \left(\sum_{(v, u) \in E} w(v, u)\right) \times \sqrt{|\{v : (v, u) \in E\}|}$$
   Multiplying total inbound edge weight by the square root of distinct referring
   files rewards files that are widely depended upon across the codebase (broad architecture)
   over files called repeatedly by a single caller.

2. **Non-Greedy Fill**:
   Introduce non-greedy knapsack fill (`--map-fill non-greedy` or as part of the fill
   strategy): when a ranked file does not fit into the remaining token budget, it is
   skipped, and subsequent candidate files that *do* fit are inspected and included.
   This prevents a single oversized file from prematurely truncating the map.

3. **CLI / Engine Options**:
   Expose `Order::InDegree` (and `--map-in-degree`) and `--map-non-greedy` across `luu map`,
   `luu chat`, `luu serve`, and `luu stdio`.

## 2026-09-04: Implementation & Measurement

Implemented in [`crates/agent-core/src/rank.rs`](../crates/agent-core/src/rank.rs) and
[`crates/agent-core/src/repo_map.rs`](../crates/agent-core/src/repo_map.rs).

### Measured on this tree at 1024 tokens:

* **In-degree ranking head**:
  1. `crates/agent-core/src/tools/mod.rs` (38.95) — broad foundational dependency
  2. `crates/luu/src/session.rs` (17.67)
  3. `crates/agent-core/src/context.rs` (16.96)
  4. `crates/agent-core/src/sandbox/policy.rs` (16.49)
  5. `crates/agent-core/src/sandbox/mod.rs` (14.94)

* **Greedy vs Non-Greedy fill at 1024 tokens**:
  * **Greedy**: Halts at `context.rs` (which exceeds the 360 remaining tokens), including only **2 files** (664 / 1024 tokens).
  * **Non-Greedy**: Skips `context.rs` and packs `sandbox/policy.rs`, `record.rs`, and `bin/loude.rs`, including **5 files** (1026 / 1024 tokens, 100% budget utilization).
