# The edit-and-re-read corpus, on a model: claims (a) and (b) of roadmap row 27

**Status:** completed — closes the first two of
[roadmap row 27](../ROADMAP/2026-09-21/README.md)'s three claims: how often a *model*
edits a file it has quoted and then asks about it, and whether it notices the divergence
or its repair. The third — drafting — is not in this file; see *Still open*. Runs on
machine 3, the model and server
[`8k-against-96k-on-the-m4-pro`](2026-09-22.8k-against-96k-on-the-m4-pro.completed.md)
set up, `luu` rebuilt from `HEAD` as
[`what-rule-c-is-worth-with-a-model`](2026-09-22.what-rule-c-is-worth-with-a-model.completed.md)
required. Evidence:
[`runs/2026-09-22.edit-reread-on-a-model/`](runs/2026-09-22.edit-reread-on-a-model/).

## The run

Exactly the protocol [`scripts/tasks/edit-reread.txt`](../scripts/tasks/edit-reread.txt)'s
own header gives: a fresh copy of
[`scripts/tasks/edit-reread/`](../scripts/tasks/edit-reread/README.md) per arm, `luu chat
--script … --allow-write . --context-limit 8192`, no gate (`--allow-write .`, no `##
job:` — the corpus deliberately keeps drafting out of this measurement). Two arms, one
flag apart: fragments only, and the same run with `--select-tokens 1024`. Against the
mock this was
[`a-corpus-that-edits`](2026-09-19.a-corpus-that-edits.completed.md); against the real
model, with the repair
([`the-newest-body-wins`](2026-09-20.the-newest-body-wins.completed.md)) live, this is
that run. `--temperature 0 --seed 1`, `qwen3.8-27b-GSQ-RCO-IQ3_S`, tokenizer as before.

A first attempt lost its recordings: `--record` was passed a path relative to the
per-arm scratch directory the script `cd`s into before invoking `luu`, so both `.jsonl`
files were written inside the directory the script then `rm -rf`'d. The transcripts and
final trees survived (redirected by the outer shell, not by `luu`) and showed both arms
already answering 13 of 13 and editing all three files correctly — enough to know the
run was worth repeating with an absolute path rather than discarding. Re-run took six
minutes; both arms below are from the second attempt.

## Claim (a): how often does a model make the edit it is told to

**Every time, in both arms.** Three edits are asked for — `greeting.rs` twice, `banner.rs`
once, `tally.rs` once — and the final tree in both `fragments.final-tree/` and
`selected.final-tree/` shows all three exactly as specified: `greet` returns `"Hey,
{name}"`, `banner()` returns `"luu 0.2"`, `THRESHOLD` is `32`, and `format.rs` (the
control) is untouched. Both arms answer all 13 turns (`[stop]`, never `[tool limit
reached]`) — a cleaner run than
[`the-8k-against-96k`](2026-09-22.8k-against-96k-on-the-m4-pro.completed.md)'s
`long-session.txt`, because this corpus's turns each ask for one thing rather than
leaving the model to explore.

## Claim (b): does the model notice, and does the repair serve it

**`diverged` is 0 in both arms.** The corpus was built to produce it —
[`a-corpus-that-edits`](2026-09-19.a-corpus-that-edits.completed.md) measured 8 of 13
turns carrying two bodies for `src/greeting.rs:1-10` on the mock, before the repair
existed. Now every one of those turns fires `superseded` instead: 8 events in the
fragments arm (turns 6 through 13, each superseding turn 1's stale read, turn 12 on
superseding turn 6's as well once a third edit lands), 16 in the selected arm — the
same 8 plus 8 more for `src/greeting.rs:8-10`, the span `--select-tokens 1024` re-reads
on its own that nobody typed, exactly the case the corpus's own comment names as "the
one that matters most." So the model is never actually shown two bodies of one path to
notice diverging; what there is to check is whether the *citation* serves it as well as
seeing the current bytes would.

**It does, at every point asked.** Turn 6 (*"what string does greet return now?"*, after
`Hello,`→`Hi,`): `"Hi, {name}"`, correct. Turn 10 (*"what is THRESHOLD now…"*, after
`16`→`32`, against the overlapping `1-6`/`1-16` grounding
[`one-path-two-bodies`](2026-09-19.one-path-two-bodies.completed.md) named as a second
blind spot): `32`, correct, with `worth_saying`'s comparison stated correctly too. Turn
12 (after `Hi,`→`Hey,`): `"Hey, {name}"`, correct. And turn 13 — no fragment attached,
answerable only from history — names all three edited files with their **current**
values (`greeting.rs`: `Hello,`→`Hi,`→`Hey,`; `banner.rs`: `luu`→`luu 0.2`; `tally.rs`:
`16`→`32`) and correctly names `format.rs` as the one file untouched. Neither arm
answers with a stale value anywhere, and turn 13's correctness does not obviously come
from the window's grounding at all: `banner.rs` is the corpus's designed blind spot
(read once, edited, never re-grounded, so nothing in the render would contradict a
stale value) and the model still reports `"luu 0.2"` — most plausibly from its own
memory of having made that edit a few turns earlier, which a real model has and the
mock's scripted replies do not model. That is a difference between this run and the
mock's, not a claim this file measures directly.

## Reading it, against `a-corpus-that-edits`'s question

The record that built this corpus asked whether the repair — trading a measured gain
(rule A's +18 points of prefix reuse) for an unmeasured one (whether re-reading a stale
span costs a real session anything) — was worth taking on faith. On this corpus, it is:
zero divergences reached the model, every re-asked value was the current one, and the
one question answerable only from memory (turn 13) was answered completely and
correctly in both arms. The result is a clean confirmation and a narrow one — one
corpus, one seed, four files, three edits — and the two blind spots
[`a-corpus-that-edits`](2026-09-19.a-corpus-that-edits.completed.md) named by
construction (`banner.rs`'s un-re-grounded edit, `tally.rs`'s overlapping ranges) were
never tested for real here either, because nothing in the script re-grounds `banner.rs`
after its edit or asks a question that would expose `tally.rs`'s two-paths-for-one-file
miscount. This run shows the repair working on the turns the corpus re-grounds; it does
not show what happens on the turns it doesn't.

## Still open

- **Claim (c), drafting, is not in this file.** *"Whether a model behaves differently
  when it knows it is drafting"* needs the gate in the loop — `## job:`, a plan, the
  floor [`the-drafts-floor`](2026-09-21.the-drafts-floor.completed.md) built — and this
  corpus deliberately keeps it out, per its own header, so that measuring the window
  is not also measuring a plan. A different script or a `luu serve` session is the run
  row 27's third claim still needs.
- **The two blind spots, on a model.** Nothing here re-grounds `banner.rs` after its
  edit or asks the question that would show `tally.rs`'s overlapping ranges being
  counted as two paths. Both are argued and reproduced on the mock; neither has been
  put in front of a model.
- **One seed.** Same caveat as every real-model run this week: `--temperature 0 --seed
  1` is one path through the sampler, and the multi-slot server nondeterminism
  [`8k-against-96k-on-the-m4-pro`](2026-09-22.8k-against-96k-on-the-m4-pro.completed.md)
  found means even that is not a full guarantee of reproducing this exact transcript.
