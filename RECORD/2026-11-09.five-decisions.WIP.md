## 51 · Environments and postures go

**Asked:** since 2026-10-23 every session the dialog starts is composed from a
runtime and one list per axis
([`policies-not-postures`](2026-10-22.policies-not-postures.WIP.md), *every
session from lists*). `[environment.*]` and `[posture.*]` were left reachable
through the API and the terminal's place picker, with no editor. Keep them as
saved combinations (A), or remove them (B)?

**Decided: B.** A session is a runtime and three lists, everywhere: the dialog,
the API, the terminal's *move*, a resume. `[environment.*]` and
`[posture.*]` are removed from `config.toml`'s schema; with 72(c)'s answer
below, there is no read-and-warn period. Row 51 shrinks to a refusal's *Add to
the policy*, which no longer waits on anything.

The recommendation's argument: the person asked for exactly this on
2026-10-23 (*siempre se podrá elegir el runtime y las políticas*), and the
dialog already remembers the last combination (`prefs.start`), which is most
of what a named preset gave.

## 72(c) · `[host.*]` goes, with no compatibility

**Asked:** `[host.<name>]` (a URL and a bearer token read from a file) opened
another luu's page before links by key existed; a `[peer.*]` does the same and
more since 2026-11-04. The one case only a token reaches is a network that
passes HTTP(S) and nothing else. Remove it (with a migration message, or
tolerated with a warning), or keep it for that case?

**Decided: remove, and forget compatibility.** *Por ahora soy el único
usuario.* The table, its routes, its form and its tests go. A `config.toml`
that still has one is refused by `deny_unknown_fields` like any unknown key;
no message is written for it. If an HTTP-only network appears, the answer is
SSH over 443 (decided 2026-11-03, *only if a deployment needs it*), not the
token.

The same answer applies to 51: nothing reads the old tables first.

## 52 · *Always in this project*

**Asked:** grants are once, for a job, or for the session. The *project* scope
— allowing `npm` once and having it hold for every session in that folder —
was put off on 2026-10-22. Build it, where, and how is it seen and taken back?

**Decided: build it as recommended.**

- A fourth answer to a held call: *always in this project*, beside once, for
  the session, and no.
- Written to **luu's** `config.toml`, keyed by the session's folder — never in
  the project's tree, so a repository cannot grant itself anything.
- Still only an `ask` turned into an `allow`; a `deny` is never grantable.
- Seen and taken back in Settings → Policies, per folder, each with its ×; and
  listed in a session's Permissions dialog beside the session's own grants.
- Where `[approvals] required = true`, the answer needs a signature like any
  other there; until row 16 gives one, it is not offered there.

## 21 · A fifth rung: fold behind, inside the live job

**Asked:** when the window no longer fits, whole turns are evicted and the
model loses them without a trace; the chat greys them out, far above the turn
that cut them. The 2026-09-18 stance was *make it visible, not configurable*.
How?

**Proposed by the person:** a new level of compaction. **Decided** as worked
out from that:

| # | Rung | Today |
| --- | --- | --- |
| 1 | rule A, a span sent once | on |
| 2 | rule B, prune behind: old turns' code becomes citations | off |
| 3 | rule C: tool output becomes citations too | off, needs B |
| **4** | **fold behind**: the live job's oldest turns become one summary | **new** |
| 5 | evict whole turns | last resort |

- The summary is the one a closed job's fold writes (`summary_text`): from the
  turns' own steps and fragments, never a model call. A 7B's account of its own
  turns is a claim; their reads and exit codes are evidence.
- A line that only moves forward, like the floor: the summary is rewritten
  when the line moves and is byte-identical between moves, so the prefix cache
  pays once per move, the shape `Eviction::Block` already has.
- Eviction stays, below it, for a window the summary does not save.
- **And it is what makes a full window visible**: a fold behind is an event,
  said in the chat at the turn that caused it — *turns 1–6 compacted: 4 800 →
  310 tokens* — which is row 21's answer and the new rung at once.
- **Off by default, and measured before it is on**: an arm of row 38's run,
  whose corpus overflows 8K. The cost to look for is the one the fold probe of
  2026-08-30 measured — a summary from evidence keeps what was done and loses
  what the model concluded in prose.

Rejected: a summary written by the model (a call per fold, and a 7B's
paraphrase in place of the record); asking the person before each cut (a
question per long turn at 8K, which is luu's main case).
