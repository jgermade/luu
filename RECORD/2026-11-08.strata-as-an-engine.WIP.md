# Strata as an engine

## The problem

Asked: *"¿qué tal si añadimos Strata como motor de inferencia?"*

[Strata](https://github.com/Niko1221/Strata) (MIT, 0.2.9 as of this writing)
is a local inference engine built around a few large mixture-of-experts models —
Qwen3.8-Flash-Next (~125B), Qwen3.6-35B-A3B and DeepSeekV4.1-Flash — that keeps
the hot experts on a 12 GB-class GPU and the rest in RAM or on SSD. It serves an
OpenAI-compatible API and an Anthropic-compatible one on `127.0.0.1:8080`.

Which is two questions, and they have different answers:

1. **Can luu send to it?** Yes, today, with no code.
2. **Should luu *start* it, as an `[engine.*]`?** Not yet: it breaks three of
   the four things an engine is in
   [`a-model-server-luu-starts`](2026-09-28.a-model-server-luu-starts.completed.md),
   and nothing has been measured that says it is worth that.

## The proposal

### Step 1 — a provider, now, and a run

Strata on this machine is an OpenAI-compatible server on loopback, which is
`backend = "openai"` and needs no `remote`:

```toml
[provider.strata]
backend = "openai"
url = "http://127.0.0.1:8080/v1"
model = "<the id GET /v1/models answers>"
context-limit = 32768   # its window is not published: say the one it serves
```

started by hand — `strata launch --family qwen --model <variant> --yes
--no-tui` — and stopped with `strata launch --stop`. `backend = "anthropic"`
with `url = "http://127.0.0.1:8080"` is the other door, and which of the two
carries tool calls and thinking better is part of what the run answers.

The run, one flag apart from what machine 3 and machine 4 already measured
(the corpus of row 38, `mixed-session.txt`, at 8K and at the window it serves):

- does it report `usage` on the stream (`stream_options.include_usage`) — the
  number the budget panel plots against our own count;
- does `tool-calls = "native"` work through its template, or only fenced;
- where its reasoning arrives: `<think>` in `content`, or a field of its own
  (`reasoning_content`), which the OpenAI backend does not read today — the
  same gap DashScope's compatible mode has, see
  [`a-live-session-moves-when-asked`](2026-11-08.a-live-session-moves-when-asked.completed.md)
  §Still open;
- what the window is, and whether `learn_window` can learn it (it asks
  llama.cpp's `/props`; Strata may answer nothing there);
- tokens per second on machine 4 (RTX 5060 Ti, 16 GB), the only box in
  [`machines.md`](../ROADMAP/2026-11-08/machines.md) Strata's GPU list covers
  with room; against the 14B and the 27B already measured there.

### Step 2 — an engine, if step 1 says it pays

`kind = "strata"` beside `llama`, `ollama` and `mlx`, only where its
differences are said rather than papered over:

| An engine is | llama / ollama / mlx | Strata |
| --- | --- | --- |
| **a child of `serve`**, dying with it | yes | **no**: `--no-tui` detaches it. Start is `strata launch … --yes --no-tui`, stop is `strata launch --stop`, ready is `GET /v1/models` answering |
| **on a port luu places** | yes, from the kind's own | **no** documented port flag: 8080, fixed — llama's default, so a llama engine is the one placed elsewhere |
| **on a model from the catalog** (a GGUF from ollama, llama.cpp, HF or `<state>/models`) | yes | **no**: its own families and variants (`--family`, `--model`, `strata models list`) in its own library |
| **luu's own copy**, one release asset checked against GitHub's sha256 | yes | **no**: its release is an install script that installs Python and downloads GPU components. Only *found on this machine* (`~/.local/bin/strata`) or a path; never `managed` |

The supervisor's whole contract — `Started` waits on a child it owns, the log
is that child's output, a crash is that child's exit — would need a second
lifecycle for a process luu asks to start and asks to stop. That is the cost,
and it is not worth paying for a server step 1 has not measured.

## Cost

Step 1: a profile and a run. Step 2: a second engine lifecycle, a per-kind
model source for the picker and the catalog, and a fixed port.

## Rejected

- **`binary = "managed"` for Strata**: luu's own copy is a release asset and a
  digest. Running a project's install script is running whatever it says that
  day, on this machine, as the person — not a copy anybody can compare a run
  against.
- **An engine first, a measurement after**: the design's targets are 7B–32B in
  8K–32K. Strata's main model is four times the top of that, which is
  interesting precisely because it is outside it — and an outside claim is the
  kind this project measures before it builds for it.

## Still open

- Whether its Anthropic-compatible door returns thinking as blocks with
  signatures, which the Anthropic backend would send back.
- Whether a fixed 8080 is really fixed (an undocumented flag, an environment
  variable): the docs name `--data-dir` and `STRATA_HOME`, not a port.
- Its window, and whether it serves one slot (`-np 1` is the condition every
  Section A run is under).
