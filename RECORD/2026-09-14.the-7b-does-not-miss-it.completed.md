# The 7B does not miss it — `--repeat-once` measured for accuracy

**Status:** closes item 1 of [`ROADMAP/2026-09-09`](../ROADMAP/2026-09-09/README.md)
— *whether a 7B misses the repetition* — the row that has stood at the top of
two revisions' order because nothing in the tree waited on it and it was first
anyway. It is also the last open line of
[`a-span-is-rendered-once`](2026-09-07.a-span-is-rendered-once.completed.md#still-open):
"the corpus and the flag now exist, the model is on a machine, and this is the
same one-flag-apart shape every other claim here has had to survive."

## The question

`--repeat-once` renders a code span once, in the oldest turn of the window that
carries it, instead of in every turn that selected it. The 2026-09-07 record
measured what it saves — up to −19.5% of the `code` bucket, on the mock, where
no answer was ever read for correctness. What it could not measure is the one
thing the flag is *for*: does a model asked a question later in the
conversation do worse when the span backing its answer is sitting in a turn
eleven messages up instead of the one it was just asked in?

## The run

`scripts/tasks/grounded.txt`, 20 turns, one flag apart, against
`qwen2.5-coder:7b` over Ollama on the M1 Pro — machine 1, the box
[`machines.md`](../ROADMAP/2026-09-09/machines.md) named as the one this
question was waiting on. Same context limit (8192), same `--select-tokens
1024`, same temperature (0) and seed (7) as the mock run, so the two are
comparable on everything but the model answering. Full transcripts and the
per-question scoring are in
[`runs/2026-09-14.repeat-once-precision/`](runs/2026-09-14.repeat-once-precision/).

Every question in `grounded.txt` has an answer that is checkable against the
fragment it attaches — three files, five questions each — plus a fourth group
that asks the same fifteen questions again with nothing attached, so the
window and eviction are what answers them.

## What it says

**Verdict-for-verdict, the two arms are identical: 11 right, 3 partial, 6
wrong, the same eleven, the same three, the same six.** Not one of the twenty
questions flipped between `off` and `--repeat-once`. Where the two arms
differ is entirely in what was *sent* — the prompt shrank at several turns by
several hundred to over a thousand tokens (e.g. turn 8: 7 611 → 6 420, a
1 191-token drop) — never in what came back scored as right or wrong.

| | `off` | `--repeat-once` | |
| --- | ---: | ---: | --- |
| prompt tokens, 20 turns | 129 970 | **124 321** | −4.4% |
| `code` bucket | 20 962 | **17 297** | **−17.5%** |
| `history` bucket | 98 720 | 96 666 | −2.1% |
| cuts | 12 | 11 | |
| mean prefix reuse | 33.4% | 39.1% | |
| verdicts (right / partial / wrong) | 11 / 3 / 6 | 11 / 3 / 6 | **identical** |

**The `code`-bucket saving replicates almost exactly**: −17.5% here against
−19.5% on the mock, on a real model asking and answering real questions rather
than a scripted reply. The `history` and cuts numbers move the same direction
as the mock's (−0.4%→−2.1%, 12→8 there against 12→11 here) but more modestly —
a smaller, noisier run, one conversation rather than a swept comparison, and
the real model's own answer lengths (which the mock does not vary) feed back
into what the window holds.

**The six wrong answers are not where `--repeat-once` could have caused
damage, and that is the finding, not a hedge.** Four of the six are wrong in
*both* arms because the model was wrong about the same thing regardless of
what was repeated — twice reading `enforcement = "kernel"` backwards (it
answered "falls back to best-effort," the opposite of what the fragment says:
missing Landlock under `kernel` enforcement denies the call), once inventing
a `Verdict` struct with fields the shown fragment never describes, once naming
the wrong record. The other two wrong answers are both in **group D**, asked
with no fragment attached at all — by the time either arm reaches that group,
the turn that originally carried the relevant span has already been evicted
in *both* arms (14 turns evicted by the end, in each), so `--repeat-once`
had nothing left to deduplicate there: the flag only changes which surviving
turn in the window renders a span, and by group D the span's owner is gone
from the window either way. The comparison the flag exists to test — *is a
span still in the window, rendered once, enough, versus rendered every turn
that selects it* — is the one this run answered cleanly, in groups A–C, where
every one of the fifteen questions scored the same in both arms.

**The backend is real this time, and the accuracy answer is what the mock
could not give: no.** A 7B did not miss the repetition, on this corpus, this
model, this seed, run once. That is the caveat every record here repeats for
a reason — n=1, one conversation, one window size, one eviction policy — and
it is also the caveat that was standing between `--repeat-once` and a default
that two roadmap revisions declined to change without it.

## What this does not answer

- **Position across the window, at a wider gap.** `grounded.txt`'s repeats are
  close — a handful of turns, not the "eleven turns up" case the 2026-09-07
  record's §Still open named as the actual open question. A longer script
  with repeats spread further apart would stress the claim harder than this
  one did.
- **A different model.** One 7B, one quantization, one serving stack. Nothing
  here says a smaller or differently-tuned model reads a distant repeat the
  same way.
- **Whether the default should flip.** This closes the *measurement*, not the
  *decision* — one run clears the bar the roadmap set, but "off by default
  until measured" becoming "on by default because measured once" is a bigger
  claim than one conversation supports. That is a separate call, for whoever
  reads this next.

## What was rejected

- **Re-running the mock's `map-order-probe` corpus instead.** It was built to
  *exclude* repetition (38 questions about 38 different files), which is
  exactly why the 2026-09-07 mock run's −9.2%-predicted/−19.5%-measured gap
  existed in the first place. It cannot answer an accuracy question about
  repeats it does not contain.
- **Scoring by a second model as judge.** Every fact in `grounded.txt` is
  checkable directly against the three files it quotes — a hand read against
  three short fragments does not need [item 11](../ROADMAP/2026-09-09/README.md)'s
  unbuilt judge, and using one here would have spent an unbuilt instrument on
  a question that did not need it.
