# The RTX holds 14B, and the roadmap's "comfortable" was a guess until now

**Status:** closed. Machine 4's inventory ceiling — "14b comfortable" on 16 GB
VRAM — has been an unverified spec claim since
[`ROADMAP/2026-09-01/machines.md`](../ROADMAP/2026-09-01/machines.md) was written.
This is the measurement, the same day as
[`landlock-holds-natively`](2026-09-08.landlock-holds-natively.completed.md),
on the same box.

## Setup

`Qwen/Qwen2.5-Coder-14B-Instruct-GGUF` (Q4_K_M, 8 988 110 272 bytes on disk).
Its `tokenizer.json` was **not** re-downloaded: a `HEAD` against both
`Qwen/Qwen2.5-Coder-14B-Instruct` and `Qwen/Qwen2.5-Coder-7B-Instruct` returned
the identical `x-linked-etag` (`443909a61d429dff23010e5bddd28ff530edda00`), so
the 7B copy already on this machine was reused — the Coder family shares one
tokenizer across sizes. `llama-server --ctx-size 8192 --n-gpu-layers 99`, same
flags as the 7B run, after killing the 7B server to free VRAM.

## The number

```
$ nvidia-smi --query-gpu=memory.used,memory.total,utilization.gpu --format=csv,noheader
11121 MiB, 16311 MiB, 7 %
```

**11.1 GB resident, on a 16.3 GB card, with ~5.2 GB free** — full GPU offload
(`n-gpu-layers 99` placed every layer; the load log shows no CPU fallback split,
unlike the 6 GB card in
[`the-floor-on-6gb`](2026-09-08.the-floor-on-6gb.completed.md), which had to be
checked because it silently didn't fully offload). Load took under 3 seconds
from a warm page cache.

Verified with a real model in the loop, the same way the Landlock record did —
`run_command` proposed and executed:

```
$ luu chat '...run_command tool...' --backend openai \
  --openai-url http://127.0.0.1:8080/v1 --model qwen2.5-coder-14b \
  --context-limit 8192 --tokenizer ~/models/qwen2.5-coder-14b/tokenizer.json

  [1] → run_command {"args":["-la"],"command":"ls"}
  [1] ← ok · commands allows `ls` · held by landlock ABI v10 + seccomp ... · 4 ms
[stop] 1765 prompt / 321 completion
```

Same verdict string as the 7B run — the sandbox doesn't care about model size,
only the process it holds.

## The verdict

**"14b comfortable" was correct**, and now it's measured rather than read off a
bandwidth column. Room for context beyond 8192 exists (~5 GB free is roughly
another 8K–16K of KV cache at this size, unmeasured precisely — see Still open),
and nothing here forced a partial offload the way the 6 GB card did at any
usable context length.

## What this does not answer

- **Not the exact context ceiling.** 8192 is what was tested, matching the 7B
  run for comparability; how far the free ~5 GB actually stretches (12K? 16K?)
  is a separate sweep, the same shape as `the-floor-on-6gb`'s but from the
  comfortable side rather than the edge.
- **Not speed**, on purpose, same as every other machine in this inventory.
- **Not the tool-call grammar**, again observed in passing rather than chased:
  this run used the same explicit, spelled-out prompt the Landlock record needed
  for the 7B to emit a real ` ```tool ` block — whether the 14B follows the
  format unprompted, where the 7B didn't, is untested here and belongs to
  [`a-grammar-for-tool-calls`](2026-09-06.a-grammar-for-tool-calls.WIP.md), not
  this record.
