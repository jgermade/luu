# grouped into four tasks that close every five turns.
#
# It exists to be run against its twin — same window, same reserve, same
# counter, same eviction policy — so that the only difference between the two
# recordings is the boundary. Folding on a task boundary is a strategy, and a
# strategy is measured against the baseline or it is an argument.
#
# The objectives group the prompts that were already grouped by subject. A task
# that cut across them would be measuring an arbitrary boundary, which is what
# the token threshold already is.
