# `steady-state.txt` is uniform Q&A with nothing attached, which is right for
# measuring eviction mechanics against a mock and useless against a model: asked
# "what does the context manager do?", a 7B answered about Python's `__enter__`
# and `__exit__`, correctly, to a question nobody had asked. Nothing in the
# prompt had ever told it this project exists.
#
# So this script attaches real files with `:file`, and every question in the
# first three groups is answerable from the text that was attached. **The last
# group attaches nothing on purpose**: it asks again about all three, so the
# answers can only come from what survived in the window. Run against
# `grounded-tasks.txt` — same prompts, same files, same order, grouped into
# tasks — that last group is the fold-fidelity probe: in the tasks run those
# three groups have been replaced by their summaries.
