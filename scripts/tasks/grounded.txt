# Twenty turns that are actually about this repository.
#
# `steady-state.txt` is uniform Q&A with nothing attached, which is right for
# measuring eviction mechanics against a mock and useless against a model:
# asked "what does the context manager do?", a 7B answered about Python's
# `__enter__` and `__exit__`, correctly, to a question nobody had asked.
# Nothing in the prompt had ever told it this project exists.
#
# So this script attaches real files with `## fragment:`, and every question in
# the first three groups is answerable from the text that was attached. **The
# last group attaches nothing on purpose**: it asks again about all three, so
# the answers can only come from what survived in the window. Run against
# `grounded-tasks.txt` — the same prompts, the same files, the same order,
# grouped into tasks — that last group is the fold-fidelity probe: in the tasks
# run those three groups have been replaced by their summaries.
#
# The line ranges are the head of each file and are checked by the run: a range
# past the end is an error, never an empty fragment, because a prompt that
# quietly lost its grounding measures the model's training instead.
